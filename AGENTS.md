# AGENTS.md

This repository defines a shared language contract. Keep it implementation-neutral: do not add
Rust/C++ APIs, parsers, renderers, generated source, or device-runtime behavior here.

- Stable decisions use `MEDUI-DEC-NNN`; never renumber or reuse an identifier.
- Stable diagnostics use `MEDUI-ENNN`; never change a published code's meaning or reuse it.
- Every normative repository rule needs a conformance case when it is mechanically testable.
- Conformance expectations describe observable behavior, not private ASTs or generated bytes.
- Do not reproduce IEC/ISO normative text or imply that conformance establishes certification.
- Run `python3 tools/validate.py` after changing decisions, schemas, manifests, or cases.
- Commit messages and PR descriptions contain no AI attribution.
